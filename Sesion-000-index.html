Sesión 00 · Encendido del sistema

Taller de Base de Datos

Unidad teórico-práctica orientada al diseño e implementación de bases de datos distribuidas: organización de archivos, acceso concurrente y optimización de consultas — construida sobre el caso de estudio de una plataforma de juego online.

MOTOR: MySQL / MariaDB · ADMIN: phpMyAdmin · MÓDULO 2 — Planificación y puesta en producción de sistemas de información

05

Consola de comandos

Todo lo que teclearás durante el curso, agrupado por sesión. Cada línea tiene botón de copiar — pégala directo en tu terminal o en la pestaña SQL de phpMyAdmin.

Preparación inicial 1 comando
mysql -u root -p Abre la consola de MySQL/MariaDB (te pedirá la contraseña de root). Alternativa 100% gráfica: abrir phpMyAdmin y usar su pestaña SQL — no necesitas esta consola si trabajas solo desde ahí.
S01 · Base de Datos del Juego 5 comandos
mysql -u root -p < scripts/01_crear_tablas.sqlCrea la base juego_online y las 6 tablas del modelo.
mysql -u root -p juego_online < scripts/02_datos_prueba.sqlCarga jugadores, items y partidas de ejemplo.
mysql -u root -p juego_online < scripts/03_consultas_leaderboard.sqlEjecuta las 4 consultas del leaderboard.
mysql -u root -p juego_online < scripts/04_procedimiento_subir_nivel.sqlCrea el procedimiento subir_nivel_jugador.
CALL subir_nivel_jugador(4, 1200);Prueba manual: sube de nivel al jugador NoobMaster.
S02 · Servidores y Roles 2 comandos
mysql -u root -p juego_online < scripts/02_roles_dba_sa_da.sqlCrea los usuarios dba_admin, soporte_sa y analista_da.
SHOW GRANTS FOR 'dba_admin'@'%';Verifica los privilegios otorgados a un usuario.
S03 · Tráfico y Concurrencia 3 comandos
mysql -u root -p juego_online < scripts/01_alter_tables_sin_downtime.sqlAgrega columnas es_unico y vendido sin bloquear la tabla.
mysql -u root -p juego_online < scripts/02_control_transacciones_deadlocks.sqlCrea el procedimiento comprar_item_unico.
CALL comprar_item_unico(5, 1, @r); SELECT @r;Prueba de concurrencia: ejecútalo en otra pestaña/terminal casi al mismo tiempo que otra compra.
S04 · Accesos y Anti-Trampas 3 comandos
mysql -u root -p juego_online < scripts/01_integridad_restricciones.sqlAgrega las restricciones CHECK de integridad.
mysql -u root -p juego_online < scripts/02_roles_permisos_jugador_moderador_admin.sqlCrea los roles jugador, moderador y administrador.
mysql -u root -p juego_online < scripts/03_prevencion_sql_injection.sqlCrea buscar_jugador_seguro y prueba el payload malicioso.
S05 · Fragmentación y Carga 3 comandos
mysql -u root -p juego_online < scripts/01_fragmentacion_particiones_region.sqlCrea Partidas_Fragmentada particionada por región.
mysql -u root -p juego_online < scripts/02_indices_matchmaking.sqlCrea los índices para acelerar el matchmaking.
mysql -u root -p juego_online < scripts/03_etl_carga_masiva.sqlCarga 5000 partidas históricas simuladas (ETL).
S06 · Respaldos y Recuperación 4 comandos
mysql -u root -p juego_online < scripts/01_auditoria_trazas.sqlCrea la tabla y el trigger de auditoría de monedas.
bash scripts/02_backup_completo.shGenera un respaldo total con mysqldump.
bash scripts/03_backup_incremental_binlog.shMuestra la configuración de respaldo incremental (binlog).
bash scripts/04_simulacro_desastre_recuperacion.shReto final: borra la base y la restaura desde el respaldo.
Respaldo y restauración manual 2 comandos
mysqldump -u root -p --single-transaction --routines --triggers juego_online > respaldo.sqlEl comando real detrás de "Exportar" en phpMyAdmin.
mysql -u root -p juego_online < respaldo.sqlEl comando real detrás de "Importar" en phpMyAdmin.
Comandos SQL de uso general 6 comandos
SHOW DATABASES;Lista todas las bases de datos del servidor.
USE juego_online;Selecciona la base de datos del proyecto.
SHOW TABLES;Lista las tablas de la base seleccionada.
DESCRIBE Jugadores;Muestra las columnas y tipos de una tabla.
SHOW GRANTS FOR CURRENT_USER();Muestra tus propios privilegios en la sesión actual.
EXIT;Cierra la consola de MySQL/MariaDB.

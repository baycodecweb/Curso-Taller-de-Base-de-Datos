📝 Examen Aleatorio

40 preguntas elegidas al azar (al menos 10 con código SQL o phpMyAdmin para analizar), repartidas lo más equitativamente posible entre las 6 sesiones


← Índice de preguntas por sesión

Cada vez que generes un examen, se eligen 40 preguntas al azar (garantizando al menos 10 con código SQL o de phpMyAdmin para revisar y detectar errores) repartidas entre las 6 sesiones, y se mezcla su orden. Todas las preguntas incluyen un fragmento de código SQL de referencia para darte contexto. Las alternativas también se mezclan. Al terminar, puedes calificarlo y ver la explicación de cada pregunta.
